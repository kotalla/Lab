## ЛР1. Инфраструктура тестирования и первые тесты

### Что сделано
Настроено рабочее место тестировщика с использованием менеджера зависимостей uv и фреймворка pytest. Для модуля pricing.py написан набор из 12 модульных тестов, проверяющих валидацию позиций заказа (R-02, R-03), расчет скидок по карте, оптовых и промокодов (R-06–R-10), а также логику доставки (R-11). Настроен CI-воркфайл .github/workflows/ci.yml, который на каждый push устанавливает uv, прогоняет тесты с измерением покрытия и исключает UI-проверки из-за отсутствия браузера в раннере.

### Покрытие
Итог прогона `uv run pytest tests/unit --cov=bookshop.pricing --cov-report=term` показал 100% покрытия строк и ветвей. Тесты на дефекты помечены маркером xfail, что позволяет сохранять общий набор зеленым при наличии багов в pricing.py. Измерение ветвей показало, что проверены все условия циклов валидации позиций заказа.

### Найденные дефекты
Выявлено 5 критических дефектов в реализации pricing.py, на каждый заведен issue и написан тест с xfail:
#1 — MAX_QTY не включен в диапазон qty (строка 77, ошибка range).
#2 — promo_applies возвращает bool вместо ожидаемого процента скидки.
#3 — discount_percent не ограничивает итоговый процент лимитом MAX_DISCOUNT.
#4 — discount_amount падает с TypeError при передаче float вместо Decimal.
#5 — calculate не может обработать валидный заказ qty=MAX_QTY из-за ошибки в check_lines.
